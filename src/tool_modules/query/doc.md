# QueryModule 工具文档

所有工具通过 `getToolDefs()` 注册到 Agent，由 LLM 调用。执行器在 `getExecutors()` 中映射。

---

## get_inventory
**描述**：查询背包中所有物品的名称和数量

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| 无 | — | — | — |

**返回示例**：
```
Iron Pickaxe x1, Cobblestone x64, Torch x16, Bread x3
```
背包为空时返回：`背包为空`

---

## get_armor
**描述**：查询当前穿戴的护甲

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| 无 | — | — | — |

**返回示例**：
```
头盔: Iron Helmet [180/240] (protection 2) armor:2 toughness:2 | 胸甲: Iron Chestplate [200/240] armor:6 toughness:2 | 护腿: 无 | 靴子: Leather Boots [55/65] armor:1
```
- `[180/240]` = 剩余耐久/最大耐久
- `(protection 2)` = 附魔
- `armor:2` = 护甲值
- `toughness:2` = 盔甲韧性（仅钻石/下界合金）

## get_offhand
**描述**：查询副手物品

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| 无 | — | — | — |

## get_nearby_entities
**描述**：视线检测前方可见的实体（生物、玩家），被方块遮挡的不可见

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| 无 | — | — | — |

**检测方式**：从眼睛位置（y+1.6）向前方 120° 扇形发射 50 条射线，最大 16 格，被方块遮挡则停止。

**返回示例**：
```
Zombie(5m), Skeleton(12m), Player(8m)
```
无可见实体时返回：`视野内无实体`

## get_block
**描述**：查询指定坐标的方块类型

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `x` | number | ✅ | X 坐标 |
| `y` | number | ✅ | Y 坐标 |
| `z` | number | ✅ | Z 坐标 |

**返回示例**：
```
(-24,71,26): Stone
```
区块未加载时返回：`(-24,71,26): 未加载`

---

## get_surrounding_blocks
**描述**：从眼睛位置发射射线扫描周围可见方块（视线检测），返回方块名和坐标

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| 无 | — | — | — |

**检测方式**：从眼睛位置向球面均匀发射 200 条射线（斐波那契球分布），最大 8 格，击中非空气方块即记录。

**返回示例**：
```
Stone(-24,71,26), Grass Block(-23,70,26), Oak Log(-22,71,27), Dirt(-24,69,26)
```
无可见方块时返回：`视野内无方块`

## look_at_block
**描述**：看向指定坐标或玩家（仅调整视角，不移动）

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `x` | number | 否 | 目标 X 坐标（与 player 二选一） |
| `y` | number | 否 | 目标 Y 坐标 |
| `z` | number | 否 | 目标 Z 坐标 |
| `player` | string | 否 | 目标玩家名（与坐标二选一） |

**返回示例**：
```
已看向坐标 (-24, 71, 26)
已看向玩家 Steve
请提供有效的 x, y, z 坐标
找不到玩家 Steve
```

## get_chest
**描述**：视线检测前方可见的箱子（普通箱子、陷阱箱），返回内容物

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|---|---|---|---|---|
| `maxDistance` | number | 否 | 8 | 最大搜索距离 |

**检测方式**：从眼睛位置向前方 120° 扇形发射 80 条射线，被方块遮挡的箱子不可见。

**返回示例**：
```
chest(-24,71,26): Iron Ingot x3, Bread x5, Torch x16
trapped_chest(-20,70,30): 空
chest(-24,71,26): 无法打开 (block is not a chest)
```
无可见箱子时返回：`视野内没有箱子`

---

## get_furnace
**描述**：视线检测前方可见的熔炉（熔炉、高炉、烟熏炉），返回烧炼状态

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|---|---|---|---|---|
| `maxDistance` | number | 否 | 8 | 最大搜索距离 |

**检测方式**：同 `get_chest`，视线射线检测。

**返回示例**：
```
furnace(-24,71,26): 输入[Iron Ore x3] 燃料[Coal x2](60%) 输出[Iron Ingot x2] 进度75%
blast_furnace(-20,70,30): 输入[空] 燃料[空](0%) 输出[空] 进度0%
```
无可见熔炉时返回：`视野内没有熔炉`

---

## get_container
**描述**：视线检测前方可见的其他容器（末影箱、木桶、漏斗、发射器、投掷器、潜影盒等）

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|---|---|---|---|---|
| `maxDistance` | number | 否 | 8 | 最大搜索距离 |

**检测方式**：同 `get_chest`，视线射线检测。

**返回示例**：
```
barrel(-24,71,26): Apple x10, Stick x32
hopper(-23,70,26): Iron Ingot x1
末影箱(-22,71,27): 需要玩家自行打开
```
无可见容器时返回：`视野内没有其他容器`

## search_web
**描述**：上网搜索 Minecraft 相关知识（合成配方、机制、攻略等）

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `query` | string | ✅ | 搜索关键词 |

**返回示例**：
```
[搜索结果] 要合成下界合金锭，需要将 4 个下界合金碎片和 4 个金锭在工作台中合成...
```
搜索失败时返回：`搜索失败: <错误信息>`
